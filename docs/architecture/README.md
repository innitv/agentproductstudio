# Индекс документов архитектуры

Двадцать документов, из которых **живых норм — четыре**. Остальные — снимки прошлых
состояний системы: они полезны как доказательная база («это уже проверяли, вот чем
кончилось»), но нормой не являются и не должны читаться как действующее правило.

Индекс появился вместо сведения аудитов в changelog (пункт 5
[studio-scope-audit-2026-07-28](studio-scope-audit-2026-07-28.md)). Отклонение от той
формулировки осознанное: аудит 2026-07-30 читал три прошлых аудита и именно из них получил
свои лучшие находки — «уже решено», «уже отклонено», «откатилось». Схлопывание в
одну строку на документ это знание уничтожает, а шум поиска снимает индекс с пометками.
Поэтому файлы остаются на месте, а навигация становится явной.

## Правило пополнения

Новый документ сюда — только если он **не** является нормой. Норма живёт там, где её
исполнитель: правило студии → `CLAUDE.md` или `claude-operating-rules.md`, механика
инструмента → навык или плагин, проверка → тест. Документ в `docs/architecture/`
доказывает и объясняет, но не предписывает — иначе появляется второй источник правды.
Адреса и чек-лист связности — навык `rule-placement`.
