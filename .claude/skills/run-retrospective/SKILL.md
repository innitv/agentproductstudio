# Run Retrospective (Разбор Завершённого Запуска)

Разбор превращает один дорогой run в правила, которые переживут сессию. Главное ограничение — стоимость: процедура, требующая получаса подготовки, не переживёт двух run. Поэтому числа собирает команда, человек тратит время только на интерпретацию, и результат ограничен пятью находками.

**Полная процедура, пороги и Definition of Done — в [`agent-pack/skills/run-retrospective/SKILL.md`](../../../agent-pack/skills/run-retrospective/SKILL.md). Следуй ей.**

## Когда использовать
- Run закрыт и был содержательным: есть повторные заходы, отклонения процесса или находки от пользователя.
- Run закрыт как `blocked`/`failed` — разбирать обязательно, независимо от размера.
- Не применяется к `outputs/temp/**` и чужим архивам.

## Ключевые шаги
- `yarn workflow:retro outputs/<slug>/<YYYY-MM-DD>` — пять метрик из артефактов, без ручного ввода. Команда ничего не пишет: закрытый run read-only.
- Раздел «Чего эти числа не видят» читается **первым** — иначе таблица метрик читается как исчерпывающая.
- Пороги: заходов на стадию > 3 → разбирать вход стадии, не исполнителя; находка `user_device` → какая автопроверка поймала бы её раньше; approval задним числом → что помешало записи вовремя; долг валидатора > 0 → причина каждой группы; пустой `inputs_used` → дисциплина ledger.
- Канал находки (`found_by`) машинно не выводится: ставь маркер `<!-- retro: pass=N found_by=user_device -->` строкой под заголовком захода, в момент захода. Без маркера канал определяется эвристикой и помечается как эвристика.

## Куда пишется результат
- **Разбор — в файл `docs/architecture/retro-<project-slug>-<YYYY-MM-DD>.md`**: числа из команды, пять находок, для каждой — выбранное решение и его статус. Датированное имя обязательно: `audit-docs.mjs` не сканирует пути в датированных снимках, а разбор законно цитирует каталоги, которые уедут в архив. **Ретро без этого файла не закрыто** — устный пересказ в чате его не заменяет.
- **Изменения** — там, где живёт правило: тест в `runtime/typescript/`, норма в `agent-pack/skills/<skill>/SKILL.md` и её краткой версии, контракт в `agent-pack/agent-contracts/`, обёртка в `.claude/agents/`.
- **В чат** — числа, пять находок и что с ними сделано. Не пересказ отчёта.

## Обязательные правила
- Каждая находка закрывается **одним из трёх**: машинная проверка, норма в skill/контракте, осознанный отказ с причиной. Находка без решения удаляется из отчёта — незакрытые наблюдения превращают ретро в ритуал.
- Новый механизм — с негативным контролем и фактическим выводом падения.
- Закрытый run не редактируется: исправленная задним числом хроника перестаёт быть свидетельством.
- Ретро ≠ аудит подсистемы. Расхождения «правило заявлено, код не исполняет» — маршрут `/subsystem-audit:audit`; ретро может его породить, но не выполняет.

## Обязательные проверки
- `yarn workflow:retro <run-dir>`
