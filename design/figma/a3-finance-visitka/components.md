## Вердикт для reuse|extend

Прямой `reuse` невозможен: токенов нет, половина UI не компонентизирована, оба component set структурно дефектны. Рекомендуемый режим — **`rebuild` (bespoke DS с нуля)** с переносом визуального направления (палитра синих, пунктирная графика, строгая сетка) и консолидацией контента в единые компоненты. Извлекаемое сырьё: палитра, стейт-матрица кнопок (после нормализации), состав экранов.
