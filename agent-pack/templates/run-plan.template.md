# Run Plan

> Шаблон `run-plan.md` для продуктового запуска. Заполняется **на старте**, до первой продуктовой стадии, а не постфактум. Разделы «Ответы на вопросы intake» и «Утверждённый план работ» — результат опроса из skill `recursive-brief` (фаза консолидации); масштаб выводится из утверждённого плана, а не выбирается отдельной категорией (`CLAUDE.md` §0.2).
>
> Scaffold `yarn workflow:start "<цель>" --scale <scale> [--profile <profile>]` создаёт базовые разделы (Статус, Запрос, Дата, Workflow Profile, План этапов, Ограничения). Разделы ниже дописываются оркестратором в том же запуске.
